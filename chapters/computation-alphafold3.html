AlphaFold3

● Draft v0.1 Updated 2026-08-27
QUICK SUMMARY
AlphaFold3 predicts a protein's 3D structure — or a protein bound to a peptide, macrocycle, or small molecule. It doesn't dock the way AutoDock/Glide does (scoring poses against a fixed receptor); it co-folds the whole complex from scratch in one pass, giving back one predicted structure with a confidence score. Installed and verified working on Woody.

Where it lives

Weights and the ~630GB genetic database set are shared on /data — nothing to download per person. You just need to be in the docker group (ask Andrew or whoever administers Woody). Your own input/output go in ~/af3/input/ and ~/af3/output/.

Quick start

HOW TO — fold a single protein

1. Get a sequence (UniProt, or wherever your target comes from). 2. Save an input JSON in ~/af3/input/:

{
  "name": "my_protein",
  "sequences": [{ "protein": { "id": "A", "sequence": "YOUR_SEQUENCE_HERE" } }],
  "modelSeeds": [1],
  "dialect": "alphafold3",
  "version": 4
}

3. Run it:

docker run -it \
    --volume $HOME/af3/input:/root/af_input \
    --volume $HOME/af3/output:/root/af_output \
    --volume /data/20260825_AndrewR_af3/models:/root/models \
    --volume /data/20260825_AndrewR_af3/databases:/root/public_databases \
    --gpus all \
    alphafold3 \
    python run_alphafold.py \
    --json_path=/root/af_input/my_protein.json \
    --model_dir=/root/models \
    --output_dir=/root/af_output

Two stages run back to back: a CPU-only genetic-search stage (slow — minutes) then GPU inference (fast — usually under a minute). Results land in ~/af3/output/<name>/<name>_model.cif.

Reading your results

REAL RESULT — FFA4 monomer (297 aa)
ranking_score 0.91 · ptm 0.88 · iptm null (single chain — expected, not an error) — data pipeline 441s, inference 53s on one A5500. ptm/iptm above 0.8 is confident; below 0.6, treat the prediction with real skepticism.

Docking: proteins, macrocycles & ligands

Add a second entity to sequences and AlphaFold3 predicts the joint complex directly — no separate docking step.

CHEMISTRY NOTE — macrocycles & peptidomimetics
AlphaFold3's protein entity only understands standard linear natural-amino-acid chains — no head-to-tail cyclization, disulfide staples, D-amino acids, or N-methylation. For a macrocyclic peptide or peptidomimetic, represent it as a ligand entity via its SMILES string instead (from ChemDraw, RDKit, PepWiz, or hand-drawn) — SMILES ring notation encodes the macrocycle directly. This is exactly what a DeepMind AlphaFold3 maintainer recommends for this case (GitHub issue #242): "specify the whole peptide plus covalently bound ligand as SMILES string, treating short peptide as a small molecule."
REAL RESULT — FFA4 + TUG-891 (native agonist, experimental EC50 ~0.2–0.4 µM)
iptm 0.94 · ranking_score 0.95 · no clashes — a strong, well-calibrated result on a molecule with known real affinity. Good benchmark for judging your own macrocycle/peptidomimetic runs against.

Shared GPUs

GOOD PRACTICE
Woody has 4 GPUs, shared. Check nvidia-smi first, then pin your run to a free one instead of grabbing all of them: --gpus device=2 (zero-indexed).

Troubleshooting

SymptomLikely causeTry this
Out-of-memory during inferenceOur 24GB cards are below AlphaFold3's officially verified 80GB tierAdd -e XLA_PYTHON_CLIENT_PREALLOCATE=false -e TF_FORCE_UNIFIED_MEMORY=true -e XLA_CLIENT_MEM_FRACTION=3.2 to enable memory spillover to system RAM
JSON fails to parseSMILES string contains unescaped \Double it to \\ before pasting
Run looks "stuck", no GPU activityNormal — CPU genetic-search stageCan take 10+ minutes before inference even starts; wait it out
